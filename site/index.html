    How to read this

    • Tier 1, confirmed: the organization, a regulator or credible reporting confirmed malicious activity.
    • Tier 2, claimed: listed by an extortion group or hacker with no confirmation. Some claims are false.
    • Tier 3, suspected-cyber outage: systems taken offline for a security reason, no attack confirmed.
    • Tier 4, technical outage: major outages attributed to non-malicious causes.
    • Dates are public disclosure dates. Many breaches started earlier; see each row's source. Record totals count victim-reported figures only.
    • This tracks organizations and events only. It never shows individuals' data or leaked files.
